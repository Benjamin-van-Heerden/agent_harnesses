Work Log - Human Harness README And Default Config Cleanup

## Overarching Goals

Create a human-facing README for the coding harness, ensure it is installed and refreshed into `.agent_core/`, and clean up the default config so the example README file inclusion is opt-in rather than active by default.

## What Was Accomplished

### Human-facing harness README

Added `coding/README.md` as a human guide to the Agent Core coding harness. The document explains:

- what the harness is and why it is project-local;
- the split between managed runtime files and project-owned durable state;
- the onboard loop and why command stdout is part of the workflow contract;
- mission control mode on the configured dev branch;
- how specs differ from ad hoc dev-branch work;
- the spec/worktree lifecycle from spec creation through PR creation;
- tasks, todos, memories, docs, and work logs;
- key `.agent_core/config.toml` fields;
- the manual and onboard-driven update mechanism;
- the development boundary that coding harness source changes belong under `coding/`.

### README install/update support

Updated `coding/setup.py` so install and update copy `coding/README.md` into `.agent_core/README.md`. This keeps the human guide available inside installed harness projects and refreshes it when the harness is updated.

Ran `python -B coding/setup.py --update` after the change, which created `.agent_core/README.md` in this repository and refreshed the installed runtime from the template.

### Default config cleanup

Updated the runtime `generate_default_config_toml()` behavior so `README.md` is no longer emitted as an active `[[files]]` entry by default. The generated default now provides the README entry as a commented example:

```toml
# [[files]]
# path = "README.md"
# description = "Project overview and setup instructions"
```

The current project `.agent_core/config.toml` was also updated to comment out the existing README file inclusion.

### Verification

- Ran focused Ruff checks on `coding/setup.py`, `coding/tests/test_setup.py`, and `coding/.agent_core/harness/src/config/main.py`.
- Ran focused setup tests for install/update preservation and config patch registry behavior.
- Ran `git diff --check`.
- Verified `.agent_core/README.md` matches `coding/README.md` with `cmp`.

- `coding/README.md` - new human-facing Agent Core coding harness guide.
