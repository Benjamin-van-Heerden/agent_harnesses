## Posture
State the current legal/procedural posture in plain language. Answer: what kind of matter is this, where does it stand now, and what is the live strategic or procedural position?

Examples: "Pre-litigation demand stage", "Application issued; answering affidavit pending", "Valuation bundle being prepared before client allocation".

If the posture is not yet known, write "Not yet recorded." Do not infer posture from folder names alone.

## Key facts
Record stable matter facts that the agent must know before doing matter-specific work. Include parties, dispute background, transaction facts, case number, important dates already established, and non-obvious constraints.

Do not use this as a chronology. Dated events belong in `info/chronology.toml`. Do not use it as a task list.

If no key facts have been established, write "Not yet recorded."

## Physical files
Record physical file references exactly as the lawyer gives them. Do not normalize, slugify, or guess file numbers.

Examples: "A123/24", "Brown lever arch marked Grobler Abbey", "Counsel brief bundle 2".

If there are no known physical files, write "None recorded."

## Workflow
Record any linked reusable workflow and the current practical workflow position. Include the workflow name, current step, blocked step, missing prerequisite, or reason no workflow applies.

If no workflow has been linked or selected, write "No workflow linked."

## What's next
Record the next concrete matter-specific action. This should be operational and specific enough for an agent or lawyer to act on.

Examples: "Draft first version of answering affidavit after source emails are summarized", "Ask lawyer whether matter should be bound to Smith Corp", "Await valuation instructions from client".

If the next action is not known, write "Not yet recorded."

## Open threads
Record unresolved questions, ambiguities, dependencies, and watch items. Include who must answer or resolve them where known.

Examples: "Need court date confirmation", "Unclear whether prescription has been interrupted", "Awaiting client to identify correct registered owner".

If there are no open threads known, write "None recorded."

## How to update this status
Update only the sections affected by the new information. Preserve already-filled sections unless the new information changes them.

If one section has been filled and another still contains only the instruction text or "Not yet recorded", do not treat the whole status as complete. Fill the missing section when reliable information becomes available.

Do not guess. If the lawyer or source material has not established the answer, use the explicit empty-state wording above.
