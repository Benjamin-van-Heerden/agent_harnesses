# Legal Agent Core

This directory contains the project-local legal harness runtime and durable practice state.

Managed runtime code lives under `.agent_core/harness/` and can be refreshed by `legal/setup.py`. Lawyer-owned practice state lives under `.agent_core/practice/`, `.agent_core/docs/legal_context.typ`, top-level `ZZ_CLIENTS/`, and top-level `WIP/`.

Use `WIP/drafts/` for drafting outside a matter. Use `WIP/experiments/` for template/style experiments and workflow iteration. Matter-specific drafts belong in the matter folder. Create organized subfolders under WIP rather than loose files at the WIP root.
